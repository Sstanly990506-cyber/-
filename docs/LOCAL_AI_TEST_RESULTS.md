# 本機網站 AI 測試結果

日期：2026-09-04。環境：使用者 Windows 電腦、原本 sanqing-local-ai 的 Python 3.12。

## 正式網站配對版追加驗證

同日完成 219 項本機測試：217 通過，2 項 Flask 驗證因本機未安裝而跳過。部署 CI 會安裝原有 Flask 依賴後執行。
追加驗證含雙重配對、精確來源限制、本機控制頁防護、短期 AI 授權不能當網站登入、對話不送雲端 API、登出競態、正式環境無狀態修改預覽／重播與資料版本衝突。
測試發現 Windows 在提早拒絕含本文的請求時可能以 TCP reset 隱藏 403 回應；已加入有大小與時間上限的本文丟棄處理，沒有解析或記錄被拒絕的內容。
正式登入、瀏覽器本機連線許可與配對需由使用者自行完成。未代填密碼、未測試真實客戶資料寫入。模型仍因可用記憶體不足而未在本次載入。

測試不讀取真實帳號或 `.env`。原網站測試會建立一次性測試帳號；發現原程式輸出臨時密碼後，已關閉該輸出，後續測試不再顯示密碼。

原有一項回歸測試固定比對舊前端版本字串；已改成檢查 index.html 與 view-loader.js 的版本一致性，保留原來 LINE 功能／權限斷言。

記憶體足夠時，啟動網站後在網站資料夾執行：

```powershell
../sanqing-local-ai/.runtime/python/python.exe -B tools/smoke_local_ai.py --model
```

這會使用本機模型測試虛構文件的 `QX-17` 問答與來源；若記憶體不足，應停止並先關閉不用的程式，而不是重裝或降低安全門檻。
