# 系統檢查記錄 2026-10-03

## 已修正

- 資料同步：儲存改為排隊，僅更新成功送出的版本快照，避免連續修改被誤判為已儲存。
- 同步與搜尋：保留未儲存修改，忽略過期搜尋結果與上一個帳號的背景回應。
- 登入：損壞的本機設定 JSON 不再阻止啟動；切換帳號清除舊資料與報表。
- LINE：取消首頁自動推播，伺服器拒絕舊頁面自動推播；查詢回覆與明確按鈕發送保留。
- 聊天室權限：一般通知帳號不能透過單筆或整份資料 API 修改聊天室資料範圍。
- 車趟帳號：工單、客戶、增量同步與執行結果只回傳車趟所需欄位，不含工單金額或客戶備註。
- 靜態檔案：停用 Flask 自動靜態路由，統一套用隱藏檔與敏感路徑限制。
- 品牌設定：模組名稱與圖示插入 HTML 前轉義。
- 財經、稽核與庫存：修正亂碼、破損 HTML 結束標籤及失效的字串插值。
- 稽核匯入：正確處理 CSV 引號、逗號、換行與 UTF-8 BOM；格式錯誤不匯入。
- 介面：增加按鈕、連結與展開標題的鍵盤焦點，避免長文字撐開財經與 LINE 卡片。
- 合併 GitHub 最新本機 AI 助理功能；統一 store 模組版本，避免不同元件持有不同登入狀態。
- 本機 AI 來源限制加入 sanqingco.com 與 www.sanqingco.com；僅明確白名單，不接受任意來源。
