# 工單協作

工單列表每列的「移動」按鈕可按住拖移；原本「點一下放開，第二下按住拖移」也保留。
移動只傳送工單與目標位置，由伺服器在交易內依最新順序處理，不重送整張工單內容。
其他使用者修改了內容或瀏覽器有尚未儲存的欄位時，仍可移動。真正的內容衝突與刪除版本檢查繼續生效。

工單畫面上方會顯示在線分頁、查看或編輯的工單與欄位。彩色游標與框線標示對方最後的滑鼠／觸碰位置。
只有雙方都顯示同一張已儲存工單時，才會把表單游標畫到對應欄位；其他工單的活動會顯示在人員列。
每個分頁有獨立識別碼，因此共用帳號也可分辨不同分頁，但辨認實際操作人員仍應各用自己的帳號。

這是約每秒嘗試一次的短間隔同步，請求較慢時會延後，不是即時共同輸入文字。
協作通道僅傳送工單識別、操作欄位與游標位置，品名、數量、價格等內容仍需儲存才會同步。
切換畫面、登出或隱藏分頁時會清除顯示；伺服器在約 15 秒後過濾離線標記。

協作資料暫存在 PostgreSQL 的 `app_presence` 表，與工單、帳款和稽核紀錄分離。
無 PostgreSQL 的本機模式使用資料目錄中的 `presence.json`。只有具工單權限的已登入使用者可存取。
協作通道失敗只顯示離線，不會禁止編輯、移動或儲存工單。

工單內容在儲存時直接寫入伺服器，成功後立即解除儲存等待；首頁統計另在背景更新。
前景分頁約每 3 秒檢查已儲存的變更，同一分頁最多一個增量同步請求；請求較慢時不疊加。
隱藏分頁暫停定時查詢，回到畫面時立即檢查。沒有相關變更時不重讀整批財務資料。

PostgreSQL 連線在同一伺服器程序內重用，每個程序最多 4 條；閒置 60 秒後回收。
每次取用會先檢查連線，交易仍各自提交或回滾，登入權限與版本衝突檢查不使用過期快取。
